# TinyURL

Сервис сокращения ссылок с возможностью управления лимитом переходов и времени жизни ссылки.

## Запуск
Программа запускается из файла /src/Main.java

## Как пользоваться
В меню есть пункты:
1. Создать короткую ссылку
2. Перейти по короткой ссылке
3. Настройки короткой ссылки
4. Сменить пользователя

### Создать короткую ссылку
После выбора этого пункта нужно ввести ссылку, для которой нужно создать короткую ссылку.
Обязательные условия для вводимой ссылки - иметь схему (https://) и домен. Пример: `https://primer.ru`.
Введенная ссылка отправляется на валидацию. В случае успешной валидации генерируется короткая ссылка,
которая будет вести на введенную ссылку в пункте `2`.
* Лимит использований по умолчанию - `5`
* Время действия короткой ссылки - `3 минуты`

Приведенные выше параметры можно регулировать в файле `config.properties`.

Лимит использований ссылки можно изменить в пункте `3`.

При первом создании ссылки создается UUID и присваивается пользователю. У всех созданных ссылок
владельцем является текущий пользователь. Сменить пользователя можно в пункте `4`.

### Перейти по короткой ссылке
После выбора этого пункта нужно ввести короткую ссылку. Введенная ссылка ищется в базе данных.
Возможные исходы:
1. Ссылка не найдена в базе данных. Это может случиться, если данная ссылка никогда не была создана
либо была удалена (вручную или автоматически).
2. Ссылка найдена, но достигнут лимит ее использования. Владелец ссылки может повысить лимит в пункте `3`.
3. Ссылка найдена, но истек срок ее действия. В этом случае ссылка скоро будет удалена автоматически.
4. Успешный исход - открывается оригинальная ссылка. У короткой ссылки повышается количество
использований на 1.

### Настройки короткой ссылки
При выборе этого пункта нужно будет ввести короткую ссылку. Текущий пользователь должен совпадать
с владельцем короткой ссылки. Если ссылка найдена и есть к ней доступ, то появится настройки:
1. Изменить лимит ссылки - позволяет изменить лимит у короткйо ссылки. Лимит должен быть больше 0.
2. Удалить ссылку - удаляет короткую ссылку.


### Сменить пользователя
Для смены пользователя нужно вести корректный UUID. 
Пример: `bc464987-c574-4a81-9c2c-e8b95692bb9c`. 


## Технические особенности
* База данных хранится в памяти. Используется ConcurrentHashMap. Ключ - короткая ссылка,
значение - контейнер со свойствами короткой ссылки.
* Автоматическое удаление истекших ссылок делается с помощью `ScheduledExecutorService`.
